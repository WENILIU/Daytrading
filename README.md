# Gap Fade v5 — 台股當沖自動交易策略

## 核心邏輯

> 開盤跳空超過大盤 ±5% 的股票，大概率是散戶情緒造成的超漲超跌。做空漲高的 / 做多跌低的，等它回歸均值。

**Alpha 來源：** 散戶造成的超漲超跌 → 均值回歸

## 策略參數

```yaml
Gap: ±5% Model C + ±3-5% (market drawdown < -5%)
Position: Model C (2-12%) × vol_mult × dir_scale × risk_scale
Equity DD Control: peak回撤>2.5% → 縮至30% | >1.25% → 縮至65%
vol_mult: target_vol / actual_vol (cap 0.5-2.0)
dir_scale: 0.5 if >80% same direction
risk_scale: 0.3 if equity DD > 2.5%
Score filter: skip < 1
Exposure: 100% (450萬，無融資)
TP: 7% (score<3) / 12% (score≥3)
SL: 5% (dynamic, capped by price limit)
Force close: 13:25
Cost: 0.109%/side (0.2%×1.7折 + 當沖稅減半)
Filters: 處置排除 + 借券確認 + 流動性300萬
整張: YES (1000股倍數)
Capital: 450萬
```

## 實盤執行時間軸

```
盤前（8:00-8:55）— 全部預先算好：
  ✓ 載入昨日收盤價（計算 gap 用）
  ✓ 載入處置股名單（排除用）
  ✓ 載入可借券清單（確認用）
  ✓ 計算 vol_mult（昨日波動率 → 今天倉位倍數）
  ✓ 讀取 equity_state.json（peak equity → risk_scale）
  ✓ 計算大盤回撤（決定是否啟用 3-5% 模組）

9:00:00 — 開盤
  │
  ├─ 9:00:01~05  TWSE API 掃描全市場（~4秒）
  │               取得所有股票開盤價
  │
  ├─ 9:00:05~08  計算 adj_gap = 個股gap - 大盤gap
  │               篩選 |adj_gap| ≥ 5%
  │               排除：處置股 / 不可借券 / 流動性<300萬
  │
  ├─ 9:00:08~10  計算每筆 Score（9個因子加權）
  │               排序：|adj_gap| 遞減
  │               計算 dir_scale（同向>80%→減半）
  │
  ├─ 9:00:10~15  逐筆下單：
  │               position = base% × vol_mult × dir_scale × risk_scale
  │               整張計算 → 送單 → 掛策略單（TP+SL）
  │
  └─ 9:00:15 完成所有下單

盤中（9:00-13:25）— 自動監控：
  │  策略單自動觸價成交（群益 SendStockStrategyDayTrade）
  │  不需要手動操作
  │
  └─ 13:25 強制平倉（交易所自動執行）

盤後（14:00）— 結算：
  │  更新 equity_state.json
  │  記錄當日損益
```

## 倉位計算（Model C）

| Score | 基礎倉位 | 說明 |
|-------|---------|------|
| ≥ 10 | 12% | 極強訊號（多重因子共振） |
| 7-9 | 9% | 強訊號 |
| 5-6 | 7% | 中等偏強 |
| 3-4 | 5% | 中等 |
| 1-2 | 4% | 偏弱但仍有效 |
| < 1 | 不下單 | 品質不足 |

**Score 因子（9個）：**
1. 大盤回撤深度
2. 大盤波動率
3. 大盤連續下跌天數
4. 3日累計跌幅
5. 當日訊號數量（高=波動日）
6. 星期效應（週二/五較好）
7. 重複出現（同一檔連續幾天出現）
8. 月份效應（7月較弱）
9. Gap 大小適中度（5-10% 最佳，>15% 反而差）

## 風險控制（五層保護，全部盤前決定）

```
第1層: Equity DD Control    → 淨值回撤>2.5% 全場縮至30%（防連續虧損）
第2層: Direction Limit      → 同向>80% 減半（防集中風險）
第3層: Vol Targeting        → 高波動日自動縮小（防尾部風險）
第4層: Per-trade SL         → 每筆最大虧 5%（防單筆失控）
第5層: Price Limit Guard    → SL 不超過漲跌停（防鎖死）
```

所有保護機制均在盤前或開盤瞬間決定，不依賴觀察成交結果。

## 注意事項

- 處置股無法當沖，程式自動排除
- 放空需確認可借券，不可借則跳過
- 開盤鎖死漲停的股票自動 skip（無法進場）
- 整張交易（1000 股倍數），不足一張自動跳過
- 450萬資金不需要融資，100% 曝險即可
